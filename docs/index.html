Everything You Need to Manage Claude Code Usage

Stay informed about every dimension of your usage without breaking your flow.

See All Your Windows at Once

Session (5h), Weekly, and Weekly Sonnet -- every window in a single view, so you never have to guess which limit you're approaching.

Know When Limits Reset

Every window shows when it resets and how long is left, so you can plan your work around resets instead of waiting and refreshing.

Never In Your Way

A percentage in the menu bar for the constant glance, ⌥⌘U for the full summary over anything including full-screen apps, and a window when you want the detail.

Quiet Until It Matters

Normal usage stays neutral instead of shouting green, so orange at 80% and red past your limit actually stand out. Every colour is backed by text, too.

No Login, No Keys

Reads the JSONL logs Claude Code already writes on your Mac. No account to connect, no API keys to manage, no config files to edit.

Honest Numbers

Deduplicated events, cache-aware pricing that tracks the current Claude models, and per-project attribution so you can see exactly where the tokens went.

Up and Running in Seconds

Install with Homebrew and start tracking your Claude Code usage.

Recommended

Homebrew

brew install hulryung/tap/claude-rate-widget

One command to install. Run brew upgrade claude-rate-widget to update.

Manual Download

Download the latest DMG from GitHub Releases and drag the app to your Applications folder.

After Install

1

Launch App

Open Claude Rate Widget from your Applications folder.

2

Grant Access

Allow the app to read ~/.claude, where Claude Code keeps its logs.

3

Pick Your Glance

Turn on the menu bar in Settings, or just press ⌥⌘U.
